# 有数资产

一个本地优先、隐私友好的全球资产管理工具。

它不是交易软件，也不是实时行情终端。它更像一本给长期投资者用的资产账本：帮你把分散在不同账户、不同市场、不同币种里的资产重新放到一张表里，看看自己现在大概有多少钱。

## 为什么会有这个工具

有些时候，普通投资者不得不开很多个“理财超市”。

可能一个人同时有 A 股账户、美股账户、港股账户、人民币基金、美元基金、港元现金，甚至还有各种银行和基金平台。它们各自都能看，但想知道自己的总资产，就要一个个软件打开，再手动加总，再做汇率换算。

这件事不难，但很烦。

有数资产就是为了解决这个问题：不追求每一秒都精确，只求心里终于有数。

## 适合谁

如果你有下面这些情况，可能会用得上：

- 同时持有 A 股、美股、港股、基金、现金等资产。
- 资产分散在多个券商、银行或基金平台。
- 需要同时看人民币、美元、港元口径下的总资产。
- 不想把真实持仓上传到云端。
- 交易频率不高，更关注阶段性的资产总览。

如果你需要秒级行情、买卖点分析、基金定投记录、复杂收益归因、分红税务统计，这个工具目前并不适合替代专业投资软件。

## 主要功能

- 账户管理：创建股票、基金、现金账户。
- 股票持仓：录入 A 股、美股、港股持仓，自动获取最新价格。
- 基金持仓：录入基金代码、份额、持有收益，自动获取最新净值。
- 现金记录：记录不同账户中的现金余额。
- 首页汇总：查看人民币、美元、港元口径下的资产总值和盈亏。
- 原始币种统计：查看不经过汇率折算的人民币、美元、港元资产。
- 数据导入导出：换设备或换浏览器时，可以导出备份，再导入恢复。
- 本地存储：数据保存在当前浏览器本地，不需要登录账号。

## 如何使用

第一次进入时，系统会展示一份模拟数据。你可以先随便点点看，熟悉页面结构。

正式使用时，建议按这个顺序：

1. 点击顶部的“清空数据”，清掉模拟数据。
2. 进入“账户”，创建你熟悉的账户名称，选择资产类别和币种。
3. 进入“股票”“基金”“现金”，分别录入已有资产。
4. 回到首页，查看总资产、原始币种资产和资产分布。
5. 定期点击“导出”，保存一份本地备份。

数据完全存在你的浏览器本地。如果换电脑、换浏览器、清理浏览器数据，原来的资产账可能就看不到了，所以导出备份很重要。

## 和同类工具有什么不同

市面上已经有一些很好用的工具。

比如《同花顺投资账本》能解决很多人民币资产统计问题，但对非人民币资产支持有限。

雪球模拟仓可以同时录入 A 股、美股、港股，也能做人民币折算，但基金和多币种资产的统一管理不够顺手。

有数资产更偏向一个轻量资产总览工具：把股票、基金、现金、多币种汇率放到一起，让分散资产能被整体看见。

## 数据和隐私

有数资产是本地优先工具。

- 不需要注册。
- 不需要登录。
- 不上传你的账户、持仓、成本、现金余额。
- 数据保存在当前浏览器的 IndexedDB 中。
- 导入导出使用 JSON 备份文件。

需要注意的是：如果你清理浏览器数据，或者换设备使用，原本的数据不会自动出现。请通过“导出”和“导入”保存与迁移资产账。

## 当前不足

这个工具目前主要用于记账和总览，还不做这些事情：

- 不记录每一笔买入卖出。
- 不统计定投计划。
- 不计算复杂收益曲线。
- 不处理分红、税费和手续费。
- 不提供投资建议。
- 不保证免费行情接口永远稳定可用。

由于使用免费公开数据源，股票价格精度和更新时间可能存在限制。当前统计目标是“足够看清资产大概情况”，不是替代券商软件做精确对账。
